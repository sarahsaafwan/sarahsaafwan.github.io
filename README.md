# Sarah Safwan Portfolio

Public website: https://sarahsaafwan.github.io/

English-only portfolio, original approved project images, 24-service catalogue, three independent market rate cards, estimate calculator, CV and portfolio PDF downloads. GitHub Pages publishes main from the repository root. The existing site is preserved in branch archive-before-portfolio-2026.

## Feedback and enquiries

The public frontend uses github-hosting.js to send public form requests to the existing secure backend at https://sarah-safwan-portfolio.alaa-saf92.chatgpt.site. That host and its R2 storage must remain active. A restricted CORS policy permits this GitHub Pages origin for public submissions and testimonials, without exposing owner management. Owner inbox links open the original trusted host and require authentication.

## Updates

Edit the HTML/CSS/JS and public assets, then commit to main. GitHub Pages handles publication. No private pricing studio, credentials, internal briefs, or submission records are in this repository.
