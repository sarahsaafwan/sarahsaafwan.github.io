# sarahsaafwan.github.io

Portfolio site for Sarah Safwan. Plain HTML and CSS, served by GitHub Pages.

Pages: `index.html` (Home), `work.html`, `services.html`, `experience.html`, `cv.html`, `contact.html`.
Shared styles in `assets/css/style.css`, script in `assets/js/main.js`. The previous one-page site is kept at `legacy.html`.

## Draft view

Content marked [PENDING] or [CONFIRM] in the brief carries `data-draft` and is hidden on the live site.
Add `?draft` to any page URL (e.g. `work.html?draft`) to see it, with image placeholders and to-do notes.
To publish an item, remove its `data-draft` attribute.

## Single-value settings

- Contact email: `EMAIL` at the top of `assets/js/main.js`
- Accent colour: `--accent` in `assets/css/style.css`
- Display font (Relationship of Mélodrame, once licensed): add its `@font-face`; `--display-word` already lists it first
