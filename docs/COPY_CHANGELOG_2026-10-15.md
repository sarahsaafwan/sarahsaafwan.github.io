# English website copy implementation | 15 October 2026

Canonical deployment: https://sarahsaafwan.github.io/ from `main` in `sarahsaafwan/sarahsaafwan.github.io`.

The complete supplied copy replaces the condensed bodies on the primary pages. Rhode retains its detailed strategy sections; the CV retains its verified facts, certificates, and downloads. Supporting routes are classified individually below; a presentation audit is not described as a complete rewrite.

## Site-wide changes

- Navigation uses **Packages**, separately from Services. The existing `calculator.html` URL remains for link compatibility and serves packages, not a public calculator.
- Em dashes are removed from authored page text, labels, metadata, and display strings. A display-only normalizer handles punctuation coming from the unchanged approved service data. Original artwork, videos, PDFs, rates, service records, and licensing terms are not altered.
- Shared end CTAs, case-study actions, feedback introduction, and the work-filter empty state use the supplied wording.
- Contact labels and success copy are updated; the obsolete estimate UI and its client handoff are removed. Existing Formspree routing, form fields, market selection, privacy acknowledgement, downloads, and package prefill remain.
- All original link destinations and local assets are retained. BellaBelles keeps its original card cover and all nine original media assets.

## Editorial source

The supplied narratives are maintained in `scripts/depth_copy_data.py` and `content/depth-copy.json`. To reapply the HTML copy, install `scripts/requirements-editorial.txt`, retain repository history for the documented base commit, run `python3 scripts/apply_depth_copy.py`, then `python3 scripts/audit_supporting_copy.py`. The production website has no new build dependency.
